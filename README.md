## 安装方法

1. 将 `BSAI_Premiere_Pro` 文件夹放入 ComfyUI 的 `custom_nodes` 目录
2. 重启 ComfyUI
3. 在节点列表中搜索 `BSAI` 或 `Premiere` 即可找到节点
4. 硬刷新浏览器（Ctrl+Shift+R）确保最新脚本加载

> 节点会自动将脚本注入 ComfyUI 前端，无需手动配置。

## 节点参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `watch_directory` | 字符串 | `output` | 监视目录路径，自动扫描该目录下的视频文件 |
| `auto_import` | 布尔值 | `True` | 开启后自动导入监视目录中的新视频文件 |
| `default_transition` | 下拉选择 | `cut` | 默认转场方式：切镜/淡入淡出/黑屏过渡/白屏过渡 |
| `transition_duration` | 浮点数 | `0.5` | 转场时长（秒），范围 0.0-5.0 |
| `output_filename` | 字符串 | `premiere_pro_output` | 输出文件名（不含扩展名） |
| `format` | 下拉选择 | `video/h264-mp4` | 输出格式：H264-MP4/H265-MP4/H264-MKV/H265-MKV/H264-MOV/VP9-WebM |
| `pix_fmt` | 下拉选择 | `yuv420p` | 像素格式：yuv420p/yuv444p/yuv422p/rgb24/bgr0 |
| `crf` | 浮点数 | `19` | 编码质量（0=无损，51=最差，建议18-23） |
| `frame_rate` | 浮点数 | `24` | 输出帧率（1-120） |

### 输入端口

| 端口 | 类型 | 说明 |
|------|------|------|
| `image` | IMAGE（可选） | 连接后进入**自动模式**，将图片+音频合成为视频 |
| `audio` | AUDIO（可选） | 配合 image 使用，提供音频轨道 |

### 输出端口

| 端口 | 类型 | 说明 |
|------|------|------|
| `video_path` | STRING | 输出视频文件的完整路径 |

## 两种工作模式

节点标题会实时显示当前模式和状态：`🎬 BSAI Premiere Pro (N clips / MM:SS) [模式]`

### ✋ 手动模式（默认）

- **触发条件**：`image` 和 `audio` 端口均未连接
- **行为**：点击「渲染输出」按钮后，将时间轴上所有片段合并为一个完整视频
- **适用场景**：编辑已有视频片段，添加转场、裁剪后输出

### ⚡ 自动模式

- **触发条件**：`image` 和 `audio` 端口均已连接
- **行为**：每次执行工作流时，自动将传入的图片+音频合成为独立视频文件并添加到时间轴
- **适用场景**：AI 生成图片和音频后，自动合成视频片段，无需手动导入
- **特点**：不会合并时间轴上已有片段，每次只处理当前传入的一组图片+音频

## 时间轴编辑器功能

双击节点或点击底部的「🎬 打开时间轴编辑器」按钮打开编辑器。

编辑器分为三大区域：
- **顶部工具栏**：导入、扫描、轨道管理、播放等操作
- **中部时间轴**：视频轨道和音频轨道，显示片段缩略图和波形
- **底部剪辑面板**：选中片段的详细参数编辑

### 顶部工具栏

| 按钮 | 功能说明 |
|------|----------|
| ☑ 自动导入 | 开启后自动监控目录，发现新视频文件即时导入到时间轴 |
| 监视目录 | 输入或修改要监控的目录路径 |
| 📁 浏览 | 打开目录浏览器，可视化选择监视目录 |
| ☑ 仅带音频 | 开启后只导入包含音频轨道的视频文件 |
| 🔍 扫描 | 立即扫描监视目录，导入所有视频文件 |
| 📥 手动导入 | 打开目录浏览器，手动选择要导入的视频文件 |
| 📂 添加外部文件 | 从任意位置选择视频文件导入，不限于监视目录 |
| 📚 历史目录 | 查看和切换之前使用过的目录，每个目录的编辑状态会被保存 |
| ✂️ 剪刀 | 进入/退出剪刀模式，用于在播放头位置剪断片段 |
| ▶️ 播放 | 从当前播放头位置开始播放时间轴上的视频 |
| ＋ 视频轨道 | 添加新的视频轨道 |
| ＋ 音频轨道 | 添加新的音频轨道 |
| 🗑 清空全部 | 清除时间轴上所有片段（需确认） |
| ☑ 批量选择 | 进入批量选择模式，可多选片段进行批量移动/删除 |
| 对齐方式 | 选择片段在画面中的对齐方式：高度对齐/宽度对齐 |
| ＋/－ | 放大/缩小时间轴（也可用鼠标滚轮） |

**视频轨道控制：**

| 🔒/🔓 | 锁定/解锁轨道（锁定后不可编辑、不可剪断、不可移动） |
| ✕ | 删除该轨道（轨道上的片段会一并删除） |

**音频轨道控制：**
| 按钮 | 功能 |
|------|------|
| 🔇 | 静音/取消静音 |
| 🎧 | 独奏（只播放该轨道音频） |
| 🔒/🔓 | 锁定/解锁轨道 |

**操作按钮：**

| 按钮 | 功能 |

| 右移 ▶ | 将片段在轨道上向右移动一位 |
| 替换视频文件 | 替换当前片段的视频源文件 |
| 🔓 取消关联 / 🔗 建立关联 | 解除或建立音视频链接 |

**片段拖拽排序：** 直接拖拽时间轴上的片段块可以在同一轨道内重新排序。

**裁剪手柄：** 每个片段左右两侧有拖拽手柄，直接拖拽即可调整裁剪起点和终点。

### 剪刀工具

1. 点击工具栏的「✂️ 剪刀」按钮进入剪刀模式
2. 播放或拖动播放头到想要剪断的位置
3. 直接点击要剪断的片段
4. 片段会在播放头位置被分成两段
5. **关联音频自动同步剪断**：如果视频片段有关联的音频，音频也会在相同时间点被剪断
6. **轨道锁定保护**：被锁定的轨道不会被剪断

> 再次点击「✂️」按钮退出剪刀模式。

### 播放预览

| 操作 | 说明 |
|------|------|
| ▶️ 播放按钮 | 从播放头当前位置开始播放 |
| 空格键 | 播放/暂停切换（编辑器打开时生效） |
| 选择片段预览 | 选中哪个片段就预览哪个片段（不是总是从第一个开始） |

- 红色竖线（播放头）会沿时间轴移动，自动对齐当前播放的片段
- 底部状态栏显示当前播放的片段名称和进度
- 暂停后可点击剪刀工具在暂停位置剪断

### 框选与批量操作

**框选：**
1. 在轨道空白区域按住鼠标左键拖拽
2. 拖出的蓝色虚线框内的片段会被选中
3. **关联自动选中**：框选视频片段时，关联的音频片段会自动同时选中（反之亦然）

**Shift+点击：**
- 按住 Shift 点击片段可多选/取消选择
- 同样会自动选中/取消关联的音视频片段

**批量操作模式：**
1. 点击「☑ 批量选择」进入批量模式
2. 点击片段进行多选
3. 可批量移动（左移/右移）或批量删除选中的片段

**框选操作栏：** 框选或 Shift+点击选中片段后，会出现操作栏：
- 左移/右移：批量移动选中片段
- 删除：批量删除选中片段
- 取消选择：退出多选状态

## 音视频关联系统

导入视频文件时，系统自动将视频和音频拆分为两个关联的片段（分别放在视频轨道和音频轨道），通过 `linked_id` 互相引用。

### 关联状态显示
- 🔗 **已链接**（黄色边框）：音视频关联，操作会同步影响双方
- 🔻 **未链接**（灰色）：独立片段，可单独操作

### 关联操作

| 操作 | 说明 |
|------|------|
| 🔓 取消关联 | 解除音视频链接，之后可单独删除视频或音频 |
| 🔗 建立关联 | 重新建立链接（需有同名文件的对应轨道片段） |
| 🔄 同步链接 | 将当前片段的裁剪/转场参数同步到关联片段 |

### 关联行为
- **删除**：关联状态下删除任一片段，另一片段会一并删除（有确认提示）
- **剪断**：剪刀工具剪断视频时，关联的音频在同一时间点同步剪断
- **框选**：框选视频时自动选中关联的音频
- **移动**：拖拽片段排序时，关联片段保持同步
- **锁定保护**：锁定轨道上的关联片段不会被剪断或移动

## 输出渲染

### 手动模式渲染
1. 确认时间轴上片段排列正确
2. 检查转场、裁剪等设置
3. 点击底部「🎞️ 渲染输出」按钮
4. 系统使用 FFmpeg `filter_complex concat` 进行无缝拼接
5. 输出文件保存到 `ComfyUI/output/` 目录
6. 渲染完成后自动弹出预览

### 自动模式渲染
1. 连接 `image` 和 `audio` 端口
2. 每次执行工作流时，自动将图片+音频合成为独立视频
3. 合成后的视频自动添加到时间轴
4. 如果已有同名文件会自动跳过（防重复）

### 无缝拼接技术
- 使用 FFmpeg `filter_complex concat` 替代 concat demuxer
- 音频流通过 `aresample=async=1:first_pts=0` 对齐
- 统一编码为 H.264/H.265 + AAC，确保拼接无闪烁/断音

## 常见问题

### Q: 底部按钮不显示？
A: 这是浏览器缓存问题。请：
1. 重启 ComfyUI
2. 硬刷新浏览器（Ctrl+Shift+R）
3. 节点已内置三层缓存破坏机制（mtime版本号 + HTML无缓存头 + 持续按钮可见性检查）

### Q: 导入后看不到视频缩略图？
A: 缩略图通过服务器端 FFmpeg 自动生成。请确认：
1. FFmpeg 已安装并可用
2. 视频文件路径正确
3. 等待几秒让缩略图异步加载

### Q: 拼接后画面闪烁/音频断裂？
A: 已使用 `filter_complex concat` 替代 concat demuxer 解决此问题。如果仍有问题，请检查所有片段的帧率和分辨率是否一致。

### Q: 时间轴窗口太小？
A: 三种方式放大：
- 点击标题栏 ⛶ 按钮全屏
- 鼠标滚轮在标题栏滚动放大窗口
- 拖拽分割线扩大时间轴区域

### Q: 如何只删除视频不删除音频？
A: 先点击剪辑面板中的「🔓 取消关联」按钮解除链接，然后即可单独删除视频或音频。

### Q: 历史目录功能是什么？
A: 每个监视目录的编辑状态（片段、裁剪、转场等）会自动保存。切换到新目录时，旧目录的编辑状态被保存；切回旧目录时，编辑状态自动恢复。

### Q: 自动模式不合并已有片段？
A: 是的设计如此。自动模式（image+audio端口连接）每次只处理当前传入的一组图片+音频，合成为独立视频文件。如需合并所有片段，断开 image+audio 连接，切换到手动模式后点击渲染。

## 技术架构

- **前端**：纯 JavaScript（非 ES Module），通过 `<script>` 标签注入 + ComfyUI 扩展注册
- **后端**：Python (aiohttp)，提供缩略图/波形/流媒体/渲染等 API 端点
- **视频处理**：FFmpeg（filter_complex concat、缩略图提取、PCM 波形采样）
- **数据存储**：时间轴数据存储在节点 properties + 服务端内存字典中
- **缓存破坏**：JS 文件 mtime 版本号 + HTML no-store 头 + 持续按钮检查
